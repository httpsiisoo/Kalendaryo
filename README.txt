KALENDARYO TREND - VS CODE

1. Open this folder in VS Code.
2. Keep index.html and sound.mp3 in the same folder.
3. Install the VS Code extension "Live Server" if you don't have it.
4. Right-click index.html -> Open with Live Server.
5. Click START. Browsers block audio autoplay until you interact with the page.

The audio file is extracted from the uploaded reference video so the visual timeline can be synchronized to it.
